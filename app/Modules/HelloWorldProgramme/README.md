# Hello World Programme Module

## Purpose
Provides a programme-scope example module with list/create/autosave behavior and widget integration.

## Scope
- Scope type: `programme`
- Module slug: `hello_world_programme`

## Main Components
- `Config/routes.php`: module route registrations
- `Controllers/HelloWorldProgrammeController.php`: module entry points
- `Models/`: entry and lock models
- `Widgets/ModuleWidget.php`: dashboard widget provider
- `Views/`: list, form, and widget templates
