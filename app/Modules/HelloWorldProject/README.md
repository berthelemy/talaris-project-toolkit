# Hello World Project Module

## Purpose
Provides a project-scope example module with list/create/autosave behavior and widget integration.

## Scope
- Scope type: `project`
- Module slug: `hello_world_project`

## Main Components
- `Config/routes.php`: module route registrations
- `Controllers/HelloWorldController.php`: module entry points
- `Models/`: entry and lock models
- `Widgets/ModuleWidget.php`: dashboard widget provider
- `Views/`: list, form, and widget templates
