# RAID Shared Module

## Purpose
Provides shared RAID controller behavior and conventions used by project RAID modules.

## Scope
- Internal shared module
- Consumers: Risk, Assumptions, Issues, Dependencies, Decisions

## Main Components
- `Controllers/BaseProjectRaidController.php`: shared CRUD and normalization logic
- Shared conventions for validation, table columns, mutation handling, and audit behavior
