# Assumptions module

The assumptions module is designed to help managers to record, prioritise and mitigate project or programme assumptions

## Core functions

The main interface will include capabilities to:

1. Add, edit or delete assumption entries
2. View a summary of the assumptions' status
3. Highlight the high priority assumptions

## Details

Each entry in the assumption register will have its own entry in a datatable, showing all the data stored for this entry.

## Data

Each assumption entry will include:

- Date entered
- Person entering the assumption entry
- assumption description
- assumption impact if invalid (high, medium, low)
- Validation actions
- Owner
- Closed (boolean)
- Closing date
- Lessons learned

## Widgets

### Assumptions overview

Designed to show a summary grid of the number of open assumptions at each priority level.

### High priority assumptions

Designed to show a list of the high priority assumptions.

Each assumption should be rendered as a link to open the assumption details
